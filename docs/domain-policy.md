# Bounded Context & Business Rules

## 1. Auth & User
- **가입 조건:** 오직 Google OAuth2 (`@inha.edu` 도메인)만 허용. 졸업생 차단.
- **기능:** JWT 기반 인증(Access/Refresh), 학번/학년 검증, 성별 입력.

## 2. Profile
- **기능:** 프로필 작성/수정/조회 (MBTI, 관심사, 연애스타일 등). 다중 이미지 업로드 가능.

## 3. Matching
- **매칭 조건:** 하루 1회만 요청 가능. 현재 진행 중인 채팅방이 있으면 매칭 불가.
- **매칭 방식:** 매일 18:01에 신청 마감 후, 저녁 시간에 Spring Scheduler로 일괄 매칭.
- **필터링 규칙:** 이성, 차단 상대, 기매칭 상대 무조건 제외 (하드 필터링).

## 4. Chat
- **기능:** 매칭 수락 시 1:1 채팅방 자동 생성. WebSocket/STOMP 기반 실시간 채팅.
- **퇴장 규칙:** 채팅방을 나가면 해당 매칭은 종료되며 새로운 매칭 신청 가능.

## 5. Report & Block
- **신고 처리:** 신고 시 자동으로 채팅방 나가기 처리 및 해당 유저 영구 차단(향후 매칭 제외).
